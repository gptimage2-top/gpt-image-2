# GPT Image 2

Official public repository for [gptimage2.top](https://gptimage2.top), a GPT Image-focused image generation and editing workspace.

This repository is the public home for product feedback, issue reports, roadmap notes, support guidance, and community discussion. It does not contain the private production source code for the live website.

## What GPT Image 2 Provides

- GPT Image-oriented text-to-image creation workflows
- Reference-led image editing workflows
- Prompt and showcase examples for structured visual tasks
- Pricing, credits, and account-based creation flows
- Multilingual public pages in English, Chinese, and Japanese
- A migration path toward Vivify for newer accounts and broader image/video creation workflows

## Public Feedback

Use GitHub Issues for:

- Broken pages, links, or layout problems
- Image generation or editing workflow feedback
- Prompt, showcase, or documentation corrections
- Pricing, credit, or onboarding clarity issues
- Accessibility and mobile usability reports

Please include the page URL, expected result, actual result, browser, device, locale, and a safe sample prompt when relevant.
